# Supportly AI — Next.js AI Customer Support SaaS Landing Page Application

A modern AI SaaS landing application for autonomous customer support, multi-source RAG knowledge ingestion, and intelligent human agent escalation.

## 🚀 Port & Development

This application runs on port **9005**:

```bash
npm install
npm run dev
```

Visit: `http://localhost:9005`

## 📄 Pages Included (4 Fully Designed Pages)

1. **Home / Landing Page (`/`)**:
   - Hero section: "Deliver Better Customer Support With AI"
   - Interactive Live AI Chatbot Simulator with quick sample prompts, streaming indicator, and verified citations
   - Autonomous resolution metrics (76.4% auto-resolved, 1.2s median latency, 94.2% CSAT)
   - Omnichannel support capabilities (Web, Slack, WhatsApp, Zendesk, Shopify)
2. **Features (`/features`)**:
   - Tone-of-Voice & Persona Guardrails Simulator (Professional, Friendly, Technical)
   - Multi-source knowledge ingestion (Website crawler, Notion, Zendesk, PDFs)
   - Sentiment-driven human agent escalation with context handoff
3. **Pricing (`/pricing`)**:
   - Free Sandbox ($0), Starter Pro ($24/mo), and Business Scale ($79/mo) plans
   - Interactive Monthly/Yearly toggle with 20% annual savings calculation
   - Comprehensive model & feature comparison matrix
4. **Integrations & SDKs (`/integrations`)**:
   - Copyable 1-line HTML embed, React / Next.js SDK snippet, and REST API cURL payload
   - Pre-built connectors (Shopify, WordPress, Zendesk, Intercom, Slack, Discord)
   - Enterprise AI Solutions Request Form with React Hook Form + Zod validation

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Obsidian & Electric Violet theme)
- **Icons:** Lucide React
- **Forms:** React Hook Form + Zod validation
